# Android Coursework Notes

> Material de estudio y ejercicios guiados de la asignatura **Desarrollo de Aplicaciones Móviles**, dictada por el profesor **Fabián Enrique Suárez Carvajal**, en la **Maestría en Gestión, Aplicación y Desarrollo de Software (MGADS)** — Universidad Autónoma de Bucaramanga (UNAB).

Este repositorio reúne guías y ejercicios base usados con fines de aprendizaje durante el curso. **No son proyectos de autoría propia**: se conservan tal como fueron entregados/seguidos, con crédito explícito a sus autores originales. Los proyectos desarrollados de forma independiente durante la misma asignatura viven en repositorios propios (ver [Proyectos propios](#proyectos-propios) más abajo).

## Contenido

### [`NetflixBasicNavigation-Fork`](NetflixBasicNavigation-Fork)
Repositorio base entregado por el profesor **Fabián Enrique Suárez Carvajal** para enseñar navegación con **Jetpack Compose Navigation** (`NavHost`, `NavController`, paso de datos entre composables), usando una interfaz inspirada en Netflix como caso de estudio.
Fuente/autor original: Fabián Enrique Suárez Carvajal — ver el [README](NetflixBasicNavigation-Fork/README.md) original del proyecto para más contexto.

### [`Race-Tracker-Corrutinas-Fork`](Race-Tracker-Corrutinas-Fork)
Codelab oficial de **Android/Google** ("Race Tracker"), usado como guía práctica para aprender **Kotlin Coroutines** (lanzamiento de corrutinas, cancelación, actualización de estado concurrente en Compose).
Fuente original: [android/codelab-android-coroutines](https://github.com/android/codelab-android-coroutines) — distribuido bajo licencia Apache 2.0 (ver [LICENSE](Race-Tracker-Corrutinas-Fork/LICENSE) dentro de la carpeta).

## Proyectos propios

Los siguientes proyectos fueron desarrollados de forma independiente como ejercicios de la misma asignatura y se mantienen en repositorios separados, documentados individualmente:

- [mars-photos-compose](https://github.com/eliangilsierra/mars-photos-compose) — consumo de API REST con Retrofit y MVVM.
- [instagram-feed-compose](https://github.com/eliangilsierra/instagram-feed-compose) — recreación de UI en Jetpack Compose.
- [compose-state-playground](https://github.com/eliangilsierra/compose-state-playground) — manejo de estado en Compose (local y con ViewModel).
